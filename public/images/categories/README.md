# Fotos de categorias pendentes

Adicione fotos autorizadas com estes nomes-base: `cabos`, `ar`, `disjuntores`, `tomadas`, `iluminacao`, `instalacao`, `ventilacao`, `acessorios`. Extensões aceitas: WebP, AVIF, PNG, JPG, JPEG (somente uma por nome).

Recomenda-se composição horizontal com o assunto central, iluminação consistente e sem marcas d'água. `npm run assets:prepare` conecta os arquivos disponíveis aos cards editoriais; categorias ausentes preservam a montagem conceitual atual. Fotos são contidas nos cards sem deformação. Nenhuma foto nova foi fornecida ou substituída nesta entrega.

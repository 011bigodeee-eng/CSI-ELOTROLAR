# Identidade oficial — aguardando arquivo original

A referência foi exibida na conversa, mas o arquivo original da logo não está disponível no workspace. Nenhuma logo oficial foi recriada, recortada ou substituída.

Envie a arte original e salve **uma** versão como `logo-oficial.webp` (também aceita PNG, AVIF, JPG ou JPEG). Preserve a arte completa, proporções, mascote, texto, cores e margens; não redesenhe. O fundo branco pode permanecer: os componentes oferecem uma base clara para leitura em fundos escuros.

Opcionalmente, forneça `favicon-oficial.png` ou WebP, contendo a versão de ícone aprovada pela empresa. Sem um ícone separado, a logo completa será usada no favicon. Não corte automaticamente o mascote ou a marca para produzir um ícone.

Execute `npm run assets:prepare` e reinicie o desenvolvimento ou faça novo build. O manifesto conecta automaticamente a logo ao cabeçalho/menu mobile, intro, seção institucional, rodapé e favicon em `/icon.svg`. A intro preserva o bloqueio da primeira pintura, sessão e botão de pular; a imagem inteira recebe revelação, luz e movimento sem deformação. A aplicação ainda depende de revisão visual com o arquivo verdadeiro.

`favicon-provisorio.svg` mantém o ícone anterior enquanto o original não é fornecido; não é a identidade oficial.
